# Tom Bar-Gal — Product design portfolio

Static portfolio homepage and three case studies: custom data management, Workplan UX improvements, and IoT maintenance.

Hosted with GitHub Pages from the main branch. No build step required. All local links work under the repository subpath.

Workplan uses a browser-side password prompt at the homepage entrance, as intended; the case study itself is a regular static page.

The bookshelf bundles Matter.js 0.20.0 (MIT); its license is in vendor/matter.LICENSE.
